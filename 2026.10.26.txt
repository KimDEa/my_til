오늘은 kant에서의 첫날.
입학식을 하고 git과 github의 차이, 현업에서의 중요성을 배움.
간단하게 많이 쓰는 git의 명령어들을 배움.
zshell의 리눅스 명령어들을 배웠다.
주로 파일을 다루는 명령어들이였고 "Tab"키의 유용성을 처음 배웠다.

***키워드***
* cd -, pwd, ls -alh등
* 파일, 폴더명의 맨앞자 입력후 tab
* "."과".."의 차이
* git의 커밋과정(관리할 폴더를 git init으로 지정하고 git add로 커밋할 파일들을 추상적인 공간에 넣어놓고 git commit -m "주석"으로 커밋하고
git push로 외부 저장소로 보낸다.)
* git은 로컬장소인 내 컴퓨터에서 언제든지 작업할수있고 외부장소인 github은 인터넷 연결이 필요하다.
* 리누스 토발즈는 대단하다.
* git은 2005년에 개발되었지만 아직까지도 개발자들의 협업에 있어서 중요한 요소인게 신기하다.
