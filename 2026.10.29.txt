오늘은 git의 심화과정이였던것 같다.
지금까지는 로컬에서 다양한 상황을 빌려 git사용법을 익혔다면 오늘은 팀을 꾸려서 테스트용 원격 저장소를 생성하고 각각 팀원들의 로컬 작업 공간을 이용해 push, pull, 파일 생성, 수정, 병합, 병합시 충돌해결을 통해 팀 프로젝트를 할때 git을 다루는 흐름을 간단하게 배운것 같다.
또한 git_graph를 설치해서 좀더 직관적으로 부모커밋으로 부터 갈라지고 다시 합쳐지는 과정을 볼수있어서 좋았다.

***키워드***
* git push origin main:test/b1 : 로컬main에서 원격test/b1브랜치로 보낸다.
* git:(main) - git pull origin test/b1 : 원격 test/b1에서 로컬 main으로 받는다.
* merge충돌 발생시 뭘 남기고 지울지 생각해야 한다.
* 팀 프로젝트를 한다면 커밋메시지의 규칙을 정말 정해야 할거같다. 추적하기 힘들다.
* git graph나 git diff, git reflog, git log등 다양한 커맨드나 툴을 이용해서 git의 커밋이 갈라지고 합쳐지는 과정을 추척하는 방법을 많이 길러야 할거 같다.
* 부족함이 많이 느껴진다. 앞으로 걱정이다. 혼자 하진말고 사람들과 서로 도우며 해야할거 같다.
